추진 시스템
- 엔진: 액체 연료 - 공기 압축, 연료 분사 연소 추력
- 로켓: 고체 연료 - 추진제 연소 추력

유도 장치
- 센서 정보 계산해 미사일 제어
- 적외선 탐지 장치, 레이더

탄두
- 신관에 의해 작동

자이로스코프
- 관성을 이용해 각도, 각속도 측정


탄도 미사일: 탄의 포물선 궤적을 탄도라 함
- 포물선 형태로 비행
- 로켓 엔진으로 추진력 + 관성 + 중력


관성 항법 장치
- 물체의 관성을 이용해 자신 위치를 계산하고 날아가는 항법
- 관성으로 가속도를 측정
- 자이로스코프로 각가속도 측정
- 이를 유도장치의 컴퓨터에서 계산해 계산 거리 측정


유도: 미사일을 표적까지 안내하는 기능
항법유도 : 현재, 목적지 위치 파악해 경로 알려줌
- 관성 항법 유도 기본
- 위성 항법 유도 : 위성의 전파신호로 위치 추정 - 방해 전파
- 지형 참조 유도 : 주변 지형 탐색 (지형 등고 대조, 디지털 영상 대조) - 사막, 바다에서 어렵

지령유도 : 날아가는 방법을 스스로 판단하지 않고, 지령에 따라 움직임
- 미사일 추적 레이더, 표적 추적 레이더 정보를 분석하여 지령 전달
- 광학 조준기, 레이저 빔으로 유도
- 구조 간단, 먼 거리에서 사용 어렵

호밍유도 : 미사일이 직접 표적을 찾음
수동 호밍 유도 : 목표물에서 나오는 신호 이용해 표적 찾음
- 표적의 열 탐지하는 적외선 탐색기
- 표적 모습 카메라로 찍어 탐색하는 영상 탐색기
- 적외선 카메라

능동 호밍 유도 : 미사일 직접 신호 보내 표적 찾음
- 레이더 탐색기 : 전파 발사, 반사 전파 수신하여 탐지
- 탐색 거리 짧아 표적 접근했을 때 사용

초기에는 관성,위성 항법 장치 -> 지령 받아서 경로 수정 -> 표적에 가까워지면 탐색기 사용해 표적 추적

유도 장치: 탐색기, 관성측정장치, 지령수신장치에서 보내는 데이터 수신하여 미사일 제어
